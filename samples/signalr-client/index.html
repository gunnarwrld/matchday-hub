⚽ Matchday Hub — live match client

A ~40-line SignalR client (the Socket.io-client equivalent). Start the API, grab a LIVE match id from GET /v1/matches?status=Live, paste it below, and connect. Goals, cards, subs, and score updates stream in as the fake aggregator reveals them.

Serve this page from an allowed origin — don't open it with file://. SignalR's negotiate is a cross-origin POST, and a file:// page sends Origin: null, which the credentialed CORS policy can't grant. From this folder run python3 -m http.server 8080 (or npx serve -l 8080) and open http://localhost:8080. That origin is in the API's Cors:AllowedOrigins defaults; add your own there if you serve it elsewhere.
